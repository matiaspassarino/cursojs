# 01 - JavaScript Fundamentos

## Contexto
Matías está aprendiendo JavaScript moderno desde los fundamentos.
Tiene experiencia básica con HTML/CSS y algo de JS.

## Objetivo
Dominar las bases de JS moderno: variables, tipos, funciones, arrays, objetos, loops, condicionales, y sintaxis ES6+.

## Convenciones
- Archivos de ejercicios: `dia-XX-tema.js`
- Cada archivo tiene comentarios explicativos en español
- Se prueba ejecutando con `node archivo.js` en terminal
